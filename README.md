1. Fork/Clone this repo
2. Go to Repository → Settings → Pages
3. Source: Deploy from branch → `main` → `/ (root)`
4. Save → Wait 2-3 minutes
5. Your site will be live at: `https://yourusername.github.io/aatif-tech`
